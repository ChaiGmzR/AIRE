# AIRE 1.2.0

## Cambios principales

- Validacion de calidad para `MAIN PCB` mediante ICT y FCT.
- Validacion de calidad para `DISPLAY` mediante prueba electrica.
- Seleccion configurable de tipo de linea y flujo.
- Persistencia local de la linea y flujo seleccionados.
- Validaciones locales de Box Id, numero de parte y piezas escaneadas.
- Generacion del archivo TXT en la carpeta de datos configurada.
- Icono de AIRE aplicado al ejecutable y accesos directos de Windows.
- Instalador EXE autocontenido con accesos directos en Escritorio y Menu Inicio.

## Instalacion

Ejecutar `pcb_boxing_system_1.2.0_installer.exe`. No se requiere PowerShell ni una instalacion previa de .NET.

Antes de instalar, confirmar que el backend compatible este desplegado y responda la version `1.2.0`.
