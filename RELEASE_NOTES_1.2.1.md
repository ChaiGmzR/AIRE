# AIRE 1.2.1

## Cambios principales

- Modal de actualizacion cuando existe una version superior.
- Descarga automatica del instalador EXE desde GitHub Releases.
- Ejecucion del instalador y reinicio automatico de la app.
- El instalador conserva el icono de AIRE y recrea los accesos directos.

## Instalacion inicial

Las versiones anteriores a `1.2.1` no contienen el actualizador. Por eso, la primera instalacion de `1.2.1` debe hacerse manualmente usando el instalador EXE.

Despues de instalar `1.2.1`, las siguientes versiones compatibles podran descargarse desde el modal de actualizacion.
