💾 SQL INSERT (backend/routes/scans.js líneas 34-41)

ℹ️ Columnas NO enviadas en INSERT

status y lot_no NO se incluyen en el INSERT. MySQL usa DEFAULT Unico para status y NULL para lot_no.

INSERT INTO box_scans (serial, box_code, first_scan, last_scan, source_file, folder_date) VALUES (?, ?, ?, ?, ?, ?) ON DUPLICATE KEY UPDATE last_scan = GREATEST(box_scans.last_scan, VALUES(last_scan)), source_file = VALUES(source_file), folder_date = COALESCE(box_scans.folder_date, VALUES(folder_date))

Captura de Pieza:

INSERT INTO box_scans (serial, box_code, first_scan, last_scan, source_file, folder_date) VALUES ('EBR80757422922602040001', 'LGB922602035972', '[HORA_BACKEND]', '[HORA_BACKEND]', 'IlsanPackingSystem', '2026-02-04') -- Donde: -- serial = Código de barras de la PIEZA (lo escaneado) -- box_code = Código de la CAJA (el BoxID ingresado) -- MySQL completa automáticamente: -- id = 1 (auto_increment) -- status = 'Unico' (DEFAULT) -- lot_no = NULL -- created_at = CURRENT_TIMESTAMP (hora del servidor MySQL)

⚠️ El BoxID NO genera INSERT

El BoxID (LGB922602035972) solo se usa para llenar la columna box_code. NO se inserta como serial.

🔧 Extracción de Part Number (backend/utils/partNumber.js)

ℹ️ Método: barcode.substring(0, 11)

Se extraen los primeros 11 caracteres del barcode para obtener el Part Number.

⚠️ El BoxID no se procesa para Part Number porque no es un serial de pieza.
